# Logo Directory

## Instructions

Place your Webpenter logo in this directory with the name: `webpenter_logo.png`

### Required:
- **File name:** `webpenter_logo.png`
- **Location:** `public/images/logo/webpenter_logo.png`
- **Format:** PNG (recommended) or JPG
- **Recommended size:** 200-400px width for best display

### Usage:
The logo will automatically appear in:
- Email invoices (embedded in email)
- PDF invoices (embedded in PDF)

### Note:
If the logo file is not found, the system will still work but without displaying the logo.
